Set up in a minute

  1. Paste the install command

    In Terminal on a Mac, or PowerShell on Windows. It downloads one small app and starts setup.

  2. Pick your school and log in

    A browser window opens your school’s own login page. Sign in like you always do.

  3. Ask your AI “am I cooked?”

    Setup connects the apps you use. Then just ask.

The exact steps for the app you use.

  1. Install Claude Desktop if you don’t have it.
  2. Run the install command. When setup asks where you want to use it, pick Claude Desktop.
  3. Quit and reopen Claude Desktop, then ask: am I cooked?
  1. Run the install command and pick Claude Code. Setup adds Am I Cooked for every project and installs its skill.
  2. Start Claude Code in any folder and ask: am I cooked?
  1. Run amicooked setup --clients chatgpt. It gives your laptop a private web address and keeps Am I Cooked running in the background.
  2. In ChatGPT on the web, open Settings, then Apps & Connectors, then Advanced settings, and turn on Developer mode.
  3. Back in Apps & Connectors, choose Create. Name it Am I Cooked, paste the address from setup, and pick OAuth.
  4. When ChatGPT asks for a code, enter the pairing code from setup. Codes last 10 minutes; amicooked pair makes a new one.

Questions

Which schools work?

Any school on D2L Brightspace. Setup has presets for 13 Ontario schools, and any other Brightspace school works with the address you log in through. Login is tested at McMaster.

Is this official?

No. Am I Cooked is an independent project. It isn’t affiliated with or endorsed by D2L or any university. Brightspace is a trademark of D2L Corporation.

Does it submit work or change anything?

No. Every tool is read-only. It reads your grades, deadlines, announcements and course files, and that’s it.

What does ChatGPT need?

A one-time link: run amicooked setup --clients chatgpt, add the address in ChatGPT with Developer mode on, and enter the pairing code. Developer mode is required for now. ChatGPT can reach Am I Cooked while your laptop is on and awake.

Where are my files saved?

Course files you download go to ~/Downloads/amicooked. Your settings and school login live in ~/.amicooked. Nothing is stored on our servers.

How do I uninstall?

Run amicooked uninstall to disconnect it from your AI apps. Add --purge to delete your login and settings too.
